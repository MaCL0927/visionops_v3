# M35.3 配对圆环轴线可视化测试

本版本在 M35.2.2 基础上只新增诊断可视化，不修改圆环—开口配对、轴线计算、抓取点选择和碰撞判断。

新增输出：

- `paired_axis_overlay.jpg`：仅显示成功配对且已成功计算三维轴线的 `foam_ring` / `ring_mouth`。
- `paired_axis_projection.json`：记录三维中心、`ring_axis_toward_camera`、二维投影端点、倾角和法向来源。

图像约定：

- 绿色：配对成功的 `foam_ring`；
- 橙色：对应 `ring_mouth`；
- 黄色长线：三维轴线投影并延伸到图像边界；
- 红色箭头：轴线有符号的朝向相机方向；
- 黄色圆圈十字：轴线接近相机光轴，二维投影小于阈值，不放大亚像素噪声。

运行命令与 M35.2 相同，结果位于每个 capture 子目录。
