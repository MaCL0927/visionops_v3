# M38.5 纯侧面外接触几何与快速门控

## 目标

M38.5 处理分割模型未输出 `ring_mouth`、RGB-D 主要只观测到外圆柱侧面的泡沫圆环。该分支不推断隐藏开口，不生成内夹爪点，也不执行 12 钟点完整夹爪碰撞。它只输出：

- 相机坐标系外接触点；
- 接触点外表面法向；
- 外夹爪向圆环内部的闭合方向；
- 无向圆柱轴线；
- 外接触局部坐标系和拟合质量。

结果明确标记 `robot_ready: false`。它不能替代内夹爪入口检查、完整夹爪碰撞、手眼变换和机器人可达性验证。

## 在线分支顺序

1. M38.1：清晰开口三维端面环带。
2. M38.3：部分开口/深孔证据约束圆柱。
3. M38.5：无 `ring_mouth` 场景的纯侧面外接触几何。
4. M38.4-C：仍无可用几何时显式拒绝。

M36 和 M37.6 代码保留，但生产配置继续关闭。

## 快速门控

对于深度推断的疑似开口，若直接观测覆盖率不足，或接近纯侧面且覆盖率不足，M38.3 不再进入耗时的内外夹持和完整夹爪检查，而是把该实例优先交给 M38.5：

```yaml
m38_branch_b:
  full_geometry_minimum_observed_opening_coverage: 0.15
  full_geometry_side_on_angle_deg: 80.0
  full_geometry_side_on_minimum_observed_opening_coverage: 0.25
```

M38.5 默认只在整帧没有任何 `ring_mouth` 实例时运行，避免抢占 M38.1/M38.3 的开口可见场景：

```yaml
m38_branch_d:
  enabled: true
  only_without_mouth: true
  require_no_mouth_instances_in_scene: true
  stop_after_first_eligible: true
  maximum_candidates_per_trigger: 3
```

## 侧面拟合

1. 腐蚀 `foam_ring` mask，排除分割边缘。
2. 膨胀并排除其他圆环 mask，减少邻居污染。
3. 使用近侧表面深度带和深度跳变过滤提取侧面。
4. 计算有组织点云法向。
5. 法向协方差最小特征方向作为无向轴线初值。
6. 保留轴向中央区域，抑制端面和圆角过渡。
7. 在小范围角度偏移内执行固定外半径圆柱拟合。
8. 通过径向残差、法向一致性、可见圆弧跨度、轴向跨度和 bootstrap 稳定性门控。
9. 在中心截面计算相机近侧外弧接触点。

闭合方向定义为外表面法向的反方向：

```text
closing_direction_camera = -outer_surface_normal_camera
```

圆柱轴线为无向量，正负号不代表哪一端是开口。

## 输出字段

最终分支：

```text

```

主要字段：

```text
scene.m38_5_branch_d
scene.m38_5_outer_contact_candidate
scene.outer_contact_candidate
scene.robot_candidate
```

候选中的关键字段：

```text
outer_contact.contact_camera_mm
outer_contact.contact_uv
outer_contact.outer_surface_normal_camera
outer_contact.closing_direction_camera
outer_contact.cylinder_axis_camera_undirected
outer_contact.contact_frame_camera
quality.radial_inlier_ratio
quality.radial_residual_median_mm
quality.radial_residual_p90_mm
quality.visible_normal_span_deg
quality.observed_axis_span_mm
quality.contact_support_error_mm
```

## 可视化

- 青色方框：外接触点；
- 绿色箭头：向内闭合方向；
- 洋红线：无向圆柱轴线；
- 标签包含 `M38.5 OUTER` 和实例 ID。
