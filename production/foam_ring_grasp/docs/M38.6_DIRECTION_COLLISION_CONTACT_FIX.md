# M38.6：方向比较、碰撞硬拒绝与近端 15% 外接触点

## 1. 目标

M38.6 在 M38.5 证据优先流程上修复四类问题：

1. 分支 C 不再把“姿态失败”或“开口证据不足”误写成“碰撞失败”；
2. 箱壁和完整夹爪箱体相交改为最终硬拒绝；
3. M38.1 不再接受第一个有效钟点，而是完整比较前 3 个优先方向；
4. M38.5 纯侧面外接触点不再放在轴向中部，而是选择相机更近的轴向端，并从该端向内移动 15%。

M36 和 M37.6 继续保留在仓库中，但生产配置仍关闭。

## 2. M38.1 方向选择

M38.1 仍使用轻量排序减少完整碰撞计算，但不会在第一个有效方向出现时立即结束。生产配置为：

```yaml
m38_branch_a:
  compare_top_clock_candidates: 3
  maximum_full_clock_candidates: 6
```

执行规则：

1. 按轻量分数排序钟点；
2. 至少完整评估前 3 个几何可用方向；
3. 从已完整评估且无碰撞的方向中选最高分；
4. 若前 3 个均失败，继续检查后续方向，直到找到有效方向或达到 6 个完整候选上限。

## 3. 碰撞硬拒绝

以下情况不再只是 warning：

```text
box_wall_status == intersects
full_gripper_static_box_status == intersects
full_gripper_motion_box_status == intersects
```

对应候选必须无效，系统继续尝试其他方向。配置：

```yaml
box_wall:
  hard_reject: false
  hard_reject_intersection: true

full_gripper_static_collision:
  hard_reject_box_intersection: true

full_gripper_motion_collision:
  hard_reject_box_intersection: true
```

`hard_reject: false` 继续保留，是为了避免将“箱体模型缺失或未配置”与“已确认相交”混为一谈。

## 4. 分支 C 简明拒绝原因

只有真正执行过完整碰撞检查，并且候选都因碰撞失败时，才显示碰撞拒绝。

| 内部代码 | 对外提示 |
|---|---|
| `m38_c_collision_blocked` | 夹爪会发生碰撞，无安全抓取方向 |
| `m38_c_pose_unreliable` | 姿态不可靠，无法确定稳定抓取方向 |
| `m38_c_opening_evidence_insufficient` | 开口观测不足，无法确认内夹爪入口 |
| `m38_c_no_accessible_opening_evidence` | 没有可用开口，只观察到侧面或证据不足 |

诊断字段：

```text
scene.m38_4_branch_c.display_reason_short
scene.m38_4_branch_c.display_reason_detail
scene.m38_4_branch_c.collision_check_performed
scene.m38_4_branch_c.collision_full_candidate_evaluated_count
scene.m38_4_branch_c.collision_rejected_candidate_count
```

在线叠加图会在顶部显示简短拒绝原因和操作提示。

## 5. M38.5 近端 15% 外接触点

纯侧面分支仍输出外接触几何，不生成内夹爪点。M38.6 对轴向位置采用以下规则：

1. 对观测侧面点沿无向圆柱轴线投影；
2. 使用 8% 和 92% 分位数恢复两个稳健轴向端点；
3. 比较两个中心线端点在相机坐标系中的 Z，选择 Z 更小、离相机更近的一端；
4. 从该端沿圆柱轴线向另一端移动总跨度的 15%；
5. 在该截面选择相机近侧外弧作为外接触点。

配置：

```yaml
m38_branch_d:
  contact_axial_lower_percentile: 8.0
  contact_axial_upper_percentile: 92.0
  contact_from_camera_near_end_fraction: 0.15
```

输出新增：

```text
outer_contact.axial_position.policy
outer_contact.axial_position.fraction_from_camera_near_end
outer_contact.axial_position.near_endpoint_camera_mm
outer_contact.axial_position.far_endpoint_camera_mm
```

注意：这里的“靠近相机端”是轴向端点的相机 Z 更小，不是接触点径向上的相机近侧外弧；两者都会参与最终接触点构造。
