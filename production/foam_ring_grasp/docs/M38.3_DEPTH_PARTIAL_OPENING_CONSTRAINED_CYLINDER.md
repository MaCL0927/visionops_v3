# M38.3：深度开口证据约束的局部圆柱拟合

## 1. 版本目标

M38.3 重构 M38.2 分支 B，用于“开口分割不完整或完全漏检，但外圆柱侧面与一部分端部仍可观察”的半侧躺/侧躺泡沫圆环。

M38.1、M36 和 M37.6 继续保留。在线顺序为：

1. 全局 M38.1 清晰开口三维端面环带；
2. 全局 M38.3 深度/分割开口证据约束圆柱；
3. 按深度层回退 M36；
4. 最后回退原 M37.6。

M38.3 不允许仅凭外圆柱侧面猜测隐藏开口。局部圆柱拟合成功后，仍必须经过内外夹持几何、邻居、箱体、完整夹爪静态与运动碰撞检查。

## 2. M38.2 在实测数据中的失败原因

在 `1785939406142` 和 `1785939473463` 中，真正需要处理的是倾斜的 `foam_ring instance 2`。RGB 可看到部分端部，深度中也存在明显偏心深孔：近侧表面约 611 mm，深孔中值约 688/689 mm，深度差约 77/78 mm。但 RKNN 没有为该实例输出 `ring_mouth`。

M38.2 只处理已经分割并配对的 mouth，因此实际送入拟合的是后方开口较完整的其他圆环，而不是 instance 2。即使进入拟合，原自由三维轴线搜索也存在多个近似局部极小值，容易找到与真实轴线近似正交的解；旧的 overlap 又以不完整/变形 mouth 面积为分母，不能稳定表达投影开口是否得到观测支持。

此外，半侧躺投影下原 M36 的二维射线边界会退化，导致 `outer_rim_boundary_ambiguous`、壁厚异常或内指包含失败，即使三维圆柱姿态已经合理也无法进入完整夹爪验证。

## 3. M38.3 方法

### 3.1 两种开口证据

分支 B 接受两种证据：

- **分割部分开口**：只有 mouth 相对 ring 中心明显偏心时才进入 M38.3；近似同心、开口清楚的实例仍由 M38.1 处理。
- **深度推断开口**：对未配对 ring，在其分割区域内部查找比近侧表面明显更深的连通区域。候选必须满足面积比例、中心偏移、边界接触、内部距离、深度差和周围近侧环带支持。

深度推断只产生“端部/孔口观测证据”，不会直接认定可抓。

### 3.2 投影约束的固定半径圆柱

M38.3 不再自由遍历三维轴线。先由 ring 主体中心指向观测开口中心，得到轴线在图像中的投影方向；随后仅沿该方向采样有限的相机视向分量。

圆柱外半径采用夹爪配置中的已知物理尺寸，只优化中心线位置并做少量固定半径迭代。候选通过以下条件联合判断：

- 外圆柱径向内点率与残差；
- 侧面法向与轴线垂直关系；
- 轴线图像投影误差；
- 可观察轴向长度；
- 端部环带支撑点与轴向锚点残差；
- 投影名义开口被真实深孔/部分 mouth 支持的覆盖率；
- 开口中心误差和可插入视角。

配置默认只评估 11 个轴线候选，而 M38.2 原自由搜索通常需要约 51 个候选。

### 3.3 名义三维内外边界

M38.3 局部姿态通过后，在恢复的开口三维平面上根据已知内外半径生成名义边界。钟点方向仍由图像坐标表达，但实际内外夹爪点来自三维圆柱截面，不再依赖近侧视角下不稳定的二维 mask 射线交点。

这只解决分支 B 的局部抓取几何。邻居点云、箱体、手指实体和运动轨迹检查仍保持原逻辑并具有最终否决权。

## 4. 关键配置

```yaml
m38_branch_b:
  enabled: true
  minimum_partial_opening_center_offset_ratio: 0.10

  inferred_opening_minimum_depth_gap_mm: 35.0
  inferred_opening_minimum_area_ratio: 0.04
  inferred_opening_maximum_area_ratio: 0.36
  inferred_opening_minimum_center_offset_ratio: 0.12
  inferred_opening_maximum_boundary_contact_ratio: 0.40

  constrained_view_component_deg: [0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
  fixed_radius_iterations: 4
  maximum_fit_points: 500
  minimum_radial_inlier_ratio: 0.60
  maximum_projected_axis_error_deg: 8.0
  minimum_synthetic_opening_coverage: 0.45

  maximum_candidate_tilt_deg: 90.0
  robot_safe_max_tilt_deg: 82.0
```

`maximum_candidate_tilt_deg` 允许近侧视角下的侧躺几何进入诊断和碰撞验证；`robot_safe_max_tilt_deg` 继续限制真正可执行的机器人候选。

## 7. 本批数据的验证结论

在开发机回放中，M38.2 原来错误处理后方 mouth-matched 圆环；M38.3 在两组关键帧均自动选中真正的倾斜 instance 2：

- `1785939406142`：深孔差 77 mm，局部拟合约 52 ms，径向内点率 0.706，投影开口覆盖率 0.838；
- `1785939473463`：深孔差 78 mm，局部拟合约 54 ms，径向内点率 0.702，投影开口覆盖率 0.469。

两组局部姿态都进入了 12 个钟点的内外夹持验证。最终没有输出机器人候选，是因为保留的邻居/完整夹爪碰撞检查判定不可安全抓取，而不是圆柱拟合未生效。

这些数据来自保存 RGB-D 的开发机离线回放，尚不能替代 RK3576 实时耗时、标定箱体和机器人试抓验证。
