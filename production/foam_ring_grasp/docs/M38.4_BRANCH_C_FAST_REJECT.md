# M38.4：分支 C 显式拒绝与快速终止

## 1. 目标

M38.4 将“几乎只看到外圆柱侧面、没有可信近端开口或内指插入证据”的场景显式归入分支 C。当前夹爪只能执行内外夹持，因此系统不再让 M36 或 M37.6 根据欠约束侧面点云猜测隐藏开口。

生产处理顺序为：

1. 全局 M38.1：清晰开口三维端面环带；
2. 全局 M38.3：部分开口/深孔证据约束的固定半径局部圆柱；
3. M38.4 分支 C：显式拒绝并快速结束本次触发。

M36 和 M37.6 的实现文件、配置和测试仍保留，但生产配置默认不执行。

## 2. 分支 C 决策

当 M38.1 和 M38.3 都没有形成最终碰撞检查通过的候选时，M38.4 根据已观测证据返回三类终止原因：

- `m38_c_no_accessible_opening_evidence`：只看到侧面或没有可信开口/端部证据；
- `m38_c_partial_opening_evidence_insufficient`：发现疑似深孔或部分开口，但端点、轴线方向或投影开口支持不足；
- `m38_c_no_collision_free_inner_outer_grasp`：开口几何可观察，但所有内外夹持钟点均被碰撞或安全检查否决。

统一操作建议为：

```text
turn_or_agitate_box
```

## 3. 生产配置

```yaml
m38_branch_a:
  enabled: true
  fallback_to_m36: false

m38_branch_b:
  enabled: true
  fallback_to_m36: false

m38_branch_c:
  enabled: true
  fast_terminate: true
  fallback_to_m36: false
  fallback_to_m37_6: false
  operator_action: turn_or_agitate_box

hybrid_grasp:
  enabled: true
  legacy_m36_enabled: false
  side_ring_fallback_enabled: false
```

恢复旧逻辑时只需修改配置，不需要恢复或复制旧代码。

## 4. 输出字段

分支 C 触发时：

```text
selected_grasp_branch = m38_4_branch_c_fast_reject
robot_candidate = null
grasp_result_status = rejected_requires_box_turning
operator_action = turn_or_agitate_box
```

主要诊断位于：

```text
scene.m38_4_branch_c
scene.terminal_decision
scene.hybrid_grasp.terminal_reject
```

`scene.m38_4_branch_c.ring_results` 会列出每个圆环是否经过 M38.1、M38.3 深孔推断和局部拟合，以及对应拒绝原因。

## 5. 快速终止保证

分支 C 终止时：

- 不调用 M36 `analyze_scene`，包括空 candidate scope；
- 不运行 M37.6 lightweight、screen、final 或 local accurate；
- `m36_attempt_count = 0`；
- `m37_fast_attempt_count = 0`；
- 显式返回需要翻动物料，不再用低残差的欠约束圆柱拟合替代可进入开口证据。
