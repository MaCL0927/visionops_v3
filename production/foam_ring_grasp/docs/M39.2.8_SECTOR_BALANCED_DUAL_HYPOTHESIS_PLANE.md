# M39.2.8 Sector-Balanced Dual-Hypothesis Annulus Plane

## Goal

M39.2.8 replaces the M39.2.7 near-flat `9 deg snap / 12 deg preserve` normal-only rule with one final branch-A plane decision made before any grasp geometry is constructed.

Only four geometry changes are in scope:

1. **Sector-balanced annulus plane**
2. **Measured vs floor-parallel dual-hypothesis competition**
3. **Floor-parallel rescue**
4. **Rebuild 3-D grasp contacts/orientation from the selected final plane**

Detection, association, clock search, box/neighbor collision checks, full-gripper checks, robot transform composition and the fixed hand-TCP-to-flange transform are unchanged.

## 1. Sector-balanced annulus plane

The M39.2.7 branch-A plane used all retained annulus depth points directly in RANSAC. If one visible crescent contributed hundreds of valid depth pixels while the opposite side contributed only a few, that dense crescent had disproportionate influence over the fitted normal and plane offset.

M39.2.8 divides the annulus around the mouth center into 16 angular sectors. Each occupied sector contributes exactly one robust 3-D representative, computed with a component-wise median. The measured normal is fit from these representatives instead of from the raw point-count distribution.

The plane offset is also re-anchored with equal-sector weighting:

```text
for each occupied sector:
    representative_3d = median(points_in_sector)
    sector_offset = -dot(representative_3d, final_normal)

plane_offset = median(sector_offsets)
```

Therefore a locally dense crescent cannot shift either the normal or the final XYZ merely by containing more depth pixels.

## 2. Measured vs floor-parallel competition

For every branch-A pair, M39.2.8 constructs two hypotheses from the same observed annulus support:

```text
H_measured:
    normal = sector-balanced measured annulus normal
    offset = sector-balanced re-anchor

H_floor_parallel:
    normal = calibrated box-floor normal toward camera
    offset = sector-balanced re-anchor to the observed annulus
```

The floor hypothesis does **not** replace ring height with a nominal box height. Only its normal is constrained to be parallel to the calibrated floor; depth/offset still comes from the current ring observations.

Each hypothesis is evaluated with equal-sector evidence:

- occupied sector count;
- good-sector angular coverage;
- sector inlier ratio;
- median of per-sector median residuals;
- p90 of per-sector median residuals;
- a competition score derived from residual and coverage quality.

The former rule:

```text
raw-vs-floor > 12 deg => preserve measured tilt
```

is no longer used.

When both hypotheses pass quality gates, measured tilt is kept only if its sector-balanced score is materially better than floor-parallel in both absolute and relative terms. Otherwise floor-parallel wins. This treats the calibrated floor as a physically meaningful prior without suppressing a genuinely tilted ring that is strongly supported by 3-D evidence.

Current production defaults:

```yaml
annulus_plane_selection:
  enabled: true
  reference: calibrated_box_floor
  sector_count: 16
  inlier_threshold_mm: 5.0
  minimum_occupied_sectors: 6
  minimum_good_sector_coverage_deg: 135.0
  minimum_sector_inlier_ratio: 0.55
  maximum_sector_residual_p90_mm: 6.0
  measured_required_score_advantage_mm: 1.0
  measured_required_score_ratio: 0.82
  floor_parallel_rescue_enabled: true
```

## 3. Floor-parallel rescue

If the measured hypothesis cannot be fit or fails its equal-sector quality gate, but the floor-parallel hypothesis is supported by the observed annulus, M39.2.8 selects the floor-parallel plane and marks:

```text
floor_parallel_rescue_applied = true
```

The pair is not accepted blindly. Rescue only restores a usable pose plane. The normal downstream safety pipeline still runs:

```text
final plane
  -> mouth/rim ray-plane intersections
  -> clock candidate geometry
  -> 2-D sweep checks
  -> local front-depth obstacle check
  -> calibrated box-wall sweep
  -> neighbor 3-D check
  -> complete gripper static collision
  -> complete pregrasp-motion collision
  -> robot candidate
```

This is intended for intermittent pose-estimation failures like the robot-test #2 case: recover the physically plausible flat pose first, then let the existing complete safety checks decide whether the grasp is executable.

## 4. One final plane drives XYZ and orientation

M39.2.7 stabilized only the plane normal after the raw annulus fit. M39.2.8 removes that second normal-only correction stage from the production branch-A path.

The selected plane is now the single source of geometry for:

- mouth center ray-plane intersection;
- mouth metric axes;
- inner rim 3-D boundary;
- outer rim 3-D boundary;
- rim midpoint;
- closing axis projected in the final plane;
- approach axis (`-final_normal`);
- grasp center;
- inner/outer contact points;
- pregrasp and finger path centers;
- swept polygons and collision volumes;
- `grasp_frame_camera` orientation;
- downstream robot pose transform.

This means a false annulus normal can no longer be corrected only at the quaternion level while leaving contacts/XYZ generated from the wrong plane.

## Diagnostics

Branch-A diagnostics now include:

```text
m38_branch_a.annulus_plane_selection.policy
m38_branch_a.annulus_plane_selection.measured
m38_branch_a.annulus_plane_selection.floor_parallel
m38_branch_a.annulus_plane_selection.measured_vs_floor_normal_deg
m38_branch_a.annulus_plane_selection.selected_hypothesis
m38_branch_a.annulus_plane_selection.selection_reason
m38_branch_a.annulus_plane_selection.floor_parallel_rescue_applied
```

The online service summary exposes the same decision under:

```text
scene_summary.selected_annulus_plane_selection
```

The legacy `flat_ring_normal_stabilization` config remains disabled only for backward compatibility and is not part of the M39.2.8 production decision chain.

## Regression tests

Synthetic regression helper:

```bash
python3 production/foam_ring_grasp/scripts/test_m39_2_8_annulus_plane_selection.py
```

Expected cases:

```text
flat + dense biased crescent -> floor_parallel
true 20-deg tilt             -> measured
measured fit failure         -> floor_parallel rescue
```

Unit tests also verify that the selected final plane is used to reconstruct rim boundaries, inserted contacts and the emitted grasp-frame axes.
