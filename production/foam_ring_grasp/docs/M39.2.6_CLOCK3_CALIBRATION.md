# M39.2.6 Clock-3 Manual Alignment Calibration

## Why clock=3 failed at many image positions

The 12-frame regression showed that the same physical foam ring produced a
clock-3 local wall estimate from 10.85 mm to 22.28 mm as it moved across the
image. The object is unchanged, so this is a viewpoint-dependent boundary
measurement error rather than a physical wall change.

For M38.1 Branch-A, the inner rim is intersected with the fitted front plane,
but the outer boundary was still taken from the raw 2-D segmentation mask.
Because the foam ring is an axial cylinder, the raw mask contains projected
side-wall pixels away from the optical axis. The clock-3 ray therefore becomes
too wide on the left side of the image and too narrow on the far right.

M39.2.6 adds an opt-in nominal 3-D wall fallback. Only when the raw outer edge
is ambiguous or outside the configured physical wall range, and only for the
configured clock hours, the outer boundary is reconstructed on the fitted front
plane using the known nominal wall thickness. Normal collision gates remain
active in the production `line.yaml`.

## 12-frame findings

- 4/12 already selected clock=3.
- 6/12 rejected clock=3 because measured wall thickness was 20.24~22.28 mm
  while the physical gate is 10~18 mm; five of these also reported
  `outer_rim_boundary_ambiguous`.
- 1/12 was rejected before clock evaluation because front-plane inlier angular
  coverage was 112.5 deg versus the 135 deg production threshold, despite a
  strong plane fit (inlier ratio 0.879, residual p95 1.94 mm).
- 1/12 measured only 10.85 mm at clock=3, causing only 0.176 mm contact
  compression and `contact_compression_out_of_range`.

## Production behavior

`config/line.yaml` enables the nominal-wall fallback only for clock=3. It does
not bypass box, neighbor, or full-gripper collision checks.

## Manual calibration-only behavior

`config/line_clock3_calibration.yaml` is TEST ONLY. It:

- forces clock=3;
- uses the nominal wall fallback;
- lowers the clean front-layer inlier angular support from 135 to 112.5 deg;
- disables box/full-gripper collision gating so a human can obtain the visual
  clock-3 pose and manually position the robot flange.

Never use this calibration config for autonomous robot execution.
