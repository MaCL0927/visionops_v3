# M39.2.2 Geometry Front-Layer Fix

## Scope

M39.2.2 keeps the existing LEFT-arm M39.2 `camera -> base -> hand_tcp -> left_link7`
transform chain unchanged.  It repairs the M38.1 Branch-A front-annulus geometry that
feeds `T_camera_grasp`.

## Root cause

Near-horizontal hollow rings may contribute two well-supported depth populations to
the same annulus mask:

1. the camera-near front foam face; and
2. the deeper inner wall / back layer.

Running one RANSAC over both populations can fit the deeper layer or a false tilted
plane spanning both layers.  The resulting bad `T_camera_grasp` then propagates
correctly through M39.2, producing a wrong robot pose or a false box collision.

## Fixes

### Strong two-layer separation

Branch A now searches for a supported depth split only when:

- the supported gap is at least 18 mm;
- both sides contain at least 15% of the valid annulus samples; and
- the camera-near side contains at least 80 points.

When all gates pass, only the camera-near layer is used for the front-plane RANSAC.
Small far-depth tails on ordinary tilted/stacked rings do not trigger the split.

### Front-layer coverage

A true camera-near subset can occupy only the visible half of the annulus.  When the
strong two-layer policy is active, the selected layer and its plane inliers must each
cover at least 135 degrees.  The original raw-annulus coverage gate remains in place.

### Discrete inlier-coverage boundary

With 16 angular sectors, coverage changes in 22.5-degree increments.  The legacy
160-degree threshold rejected a seven-sector plane (157.5 degrees) by only 2.5
degrees.  The normal Branch-A threshold is now 150 degrees, which still requires
seven sectors.

### Robot-safe tilt hard gate

`robot_safe_max_tilt_deg` is now a real robot-candidate gate rather than only a sort
preference.  A geometrically valid pose above the robot-safe tilt remains available
for diagnostics (`eligible=true`) but gets `robot_eligible=false` and cannot create a
`robot_candidate`.

## M39.2 transform chain

No calibration or static tool transform is changed in this version.  The LEFT-arm
ANDREFF hand-eye result and the configured Visual-Grasp/TCP/flange transforms remain
exactly as in the supplied M39.2 baseline.
