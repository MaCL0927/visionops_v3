# M30.1 洗衣液抓取任务集成说明（历史版本）

基于 M30 新增 `production/detergent_grasp` 独立任务：

1. 新增 OBB Runtime/App/Collector 三服务与独立模型目录；
2. 支持 `big/small/head/box` 类别的可配置 ID/名称映射；
3. 将 `head` 一对一关联到大/小瓶，`center_px` 输出实际抓取点；
4. 机器人协议保留既有字段，新增 `target_type/object_center_px/grasp_point_px/obb_points`；
5. M30.1 的 `angle_deg` 仅为 `[-90,90]` 无向 OBB 长轴角；M30.2 已扩展为瓶体 `[-180,180)` 的把手有向角；
6. MJPEG 随 `active_camera.json` 自动切换；
7. 生产 App 每完成一帧就推送一帧，不设置独立 `push_hz`；
8. 相机设置页面切换相机时会重启本任务 Runtime/App。
