# M40.1 Plastic Bag Grasp — Robot Protocol + FPS Fast Path

本版本将透明包装袋任务收敛为“检测整个包装目标并返回 bbox 中心”。

- 新 production：`production/plastic_bag_grasp`。
- detection 类别：`plastic_bag`，默认 class_id=0。
- 最多返回 1 个目标，默认按最高 confidence 选择。
- `center_px` = 检测框中心，打结头部的位置/方向不参与计算。
- `position_camera` 继续保留，与 tube_pick 统一；D2C 无效时返回零向量但不丢弃 RGB 目标。
- 协议保持 `:9001/vision` + `type=detection` + `items[]` 五个核心字段。
- `request_id` 显式 trigger 走可靠路径，连续帧仍 latest-only。
- 保留 M32.8 系列 FPS 优化：双线程流水线、容量 1 队列、raw local HTTP、延迟 JSON decode、共享 RGB/Depth、小 ROI depth sample。
- 删除固定 5Hz 推送概念；默认推理上限 30 FPS，推送随实际完成推理 FPS。
- Runtime 生产环境建议 `VISIONOPS_RUNTIME_HTTP_WORKERS=1`。
- 源 RGB 尺寸不写死为 640x480；支持当前模型验证场景的 1280x720 源图 + 640x640 ROI，并始终向机器人返回原图坐标。
