# M32.4.3 模型验证结果 ROI 编辑器图像修复

## 问题

M32.1 加入采集 ROI 弹窗后，页面中同时出现两个 `.roi-editor-stage`。
模型验证页仍通过 `document.querySelector(".roi-editor-stage")` 获取舞台节点，
因此总是选中 DOM 中排在前面的采集 ROI 舞台。采集 ROI 弹窗关闭时该舞台尺寸接近 0，
导致模型验证的结果 ROI 图像和画布被按错误容器缩放/定位，弹窗表现为黑屏。

## 修复

- 为采集 ROI 舞台增加唯一 ID：`capture-roi-stage`。
- 为结果 ROI 舞台增加唯一 ID：`validate-roi-stage`。
- `capture.js` 和 `validate.js` 均使用 `getElementById` 获取各自舞台。
- 不修改 Runtime 的 `/api/runtime/roi` 接口，也不改变模型输入 ROI 或采集 ROI 语义。

## 验证

1. 打开“模型验证”。
2. 点击“绘制 ROI”。
3. 弹窗应显示当前完整相机快照。
4. 拖动黄色结果 ROI 并保存。
5. 采集上传页的蓝色采集 ROI 仍可正常打开和保存。
