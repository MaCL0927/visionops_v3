# M32.8.2 Collector Raw Runtime Proxy

## 1. 问题

工厂模式“模型验证/实时检测”通过 Collector 转发：

```text
浏览器 -> Collector -> C++ Runtime
```

M32.8.1 之前，Collector 的 Runtime 客户端仍使用 `urllib.request.urlopen()`。
在 RK3576 现场对同一个 `/api/runtime/infer_once` 做 A/B 测试：

```text
urllib       avg=62.08 ms, fps=16.11
raw_socket   avg=36.86 ms, fps=27.13
```

因此即使 Runtime 本身可以达到约 25~27 FPS，工厂模式仍会被 Collector 的
urllib 固定延迟限制。

## 2. 修改范围

本版本只修改 Collector 到 Runtime 的代理链路：

- `apps/collector_web/backend/runtime_client.py`
- `apps/collector_web/backend/main.py`

Gateway 和 Business App 的 Collector 下游客户端继续使用原来的 urllib，未修改
生产业务 App 的推理、机器人通信、工厂/生产模式切换或 NPU 独占逻辑。

## 3. 新链路

当 `runtime_url` 为本机 HTTP 地址时：

```text
http://127.0.0.1:<port>
http://localhost:<port>
http://[::1]:<port>
```

Collector 使用：

```text
TCP_NODELAY
+ HTTP header/body 一次 sendall
+ 原始响应头/响应体读取
```

非本机 URL 自动保持 urllib。只有 raw socket 在发送请求前连接失败时才允许回退
urllib；请求已经发送后若响应异常，不会再次发送 POST，避免重复执行 `infer_once`。

## 4. 协议兼容

Raw 代理保留：

- HTTP 状态码，包括 4xx/5xx；
- `application/json` 与 `image/jpeg`；
- Runtime JSON 响应体；
- Snapshot 的 `Cache-Control`、帧 ID、Trace ID 和时间戳头；
- query string；
- `Content-Length`、连接关闭响应和 chunked 响应读取。

Collector 返回额外诊断头：

```text
X-VisionOps-Upstream-Transport: raw_socket
```

Collector 状态接口增加：

```json
{
  "proxy": {
    "runtime_transport": {
      "raw_local_enabled": true,
      "raw_request_count": 100,
      "raw_connect_failure_count": 0,
      "urllib_request_count": 0,
      "last_transport": "raw_socket"
    }
  }
}
```

## 5. 部署

本版本仅修改 Python Collector，不需要重新编译 C++ Runtime。

```bash
sudo systemctl restart visionops-v3-detergent-grasp-collector.service
```

脚本启动时停止旧 Collector 后执行：

```bash
cd /opt/visionops_v3
bash production/detergent_grasp/scripts/start_collector.sh
```

浏览器强制刷新：

```text
Ctrl + Shift + R
```

## 6. 验证

查看代理传输状态：

```bash
curl -s http://127.0.0.1:18096/api/collector/status \
  | python3 -m json.tool
```

端口以现场 Collector 实际配置为准。应看到：

```text
proxy.runtime_transport.last_transport = raw_socket
proxy.runtime_transport.raw_request_count 持续增长
proxy.runtime_transport.urllib_request_count = 0
```

直接查看一次代理响应头：

```bash
curl -sS -D - -o /dev/null \
  -X POST http://127.0.0.1:18096/api/runtime/infer_once
```

应包含：

```text
X-VisionOps-Upstream-Transport: raw_socket
```

## 7. 预期

在没有其他 Runtime 调用方竞争的情况下，工厂模式 Collector 代理开销应接近
M32.8.1 的 App raw IPC。现场具体 FPS 仍受 Runtime 推理耗时及是否存在并发请求
影响。
