# M33.1 SAM 智能框选与少样本分割优化

## 目标

M33.1 在服务端内置标注器中增加可选的 SAM 智能框选能力，并修正快速学习对嵌套分割标签不友好的默认训练参数。

该阶段优先解决“单张图片实例很多、手工逐点描边耗时”的问题，不尝试一次性实现无人审核的全图自动标注。

## 推荐工作流

```text
人工粗框一个实例
  -> SAM 根据 box prompt 生成多边形
  -> 人工选择类别并微调
  -> 完成 5～10 张姿态和遮挡多样的图片
  -> 快速学习临时模型
  -> 批量预标注剩余图片
  -> 人工确认 labels_auto
```

SAM 的作用是生成单个目标的精细轮廓，不依赖当前 batch 已经标注了多少图片。快速学习继续负责批量预标注。

## Web 操作

1. 将任务类型切换为 `Segmentation 多边形`。
2. 可先在“SAM 生成后使用的类别”中固定 `foam_ring` 或 `ring_mouth`；留空则每次弹窗选择。
3. 点击 `R SAM 智能框选`，或按键盘 `R`。
4. 用矩形框略微包住一个目标。
5. 等待 SAM 返回多边形；固定类别时会直接加入当前标注。
6. 继续框选下一个目标；按 `Esc` 或再次点击按钮退出。
7. SAM 生成的多边形仍可使用现有顶点拖动功能修正。

## 服务端接口

```text
GET  /api/annotator/sam/status?batch_id=<batch_id>
POST /api/annotator/sam/predict-box?batch_id=<batch_id>
```

预测请求：

```json
{
  "filename": "sample.jpg",
  "bbox": [100, 80, 260, 230]
}
```

预测响应中的 `polygon` 使用原始图片像素坐标，可直接进入现有标注器和 YOLO segmentation 保存流程。

## 模型与环境

仓库不包含 SAM 权重。默认按顺序查找：

```text
models/pretrained/sam2.1_s.pt
models/pretrained/mobile_sam.pt
```

也可以设置：

```bash
export VISIONOPS_ANNOTATOR_SAM_MODEL=/absolute/path/to/sam2.1_s.pt
export VISIONOPS_ANNOTATOR_SAM_DEVICE=0
```

服务端 Python 环境必须能导入 `ultralytics`。模型采用惰性加载，启动 Server API 时不会立即加载 PyTorch/SAM；第一次框选时才加载模型。

可选参数：

```bash
VISIONOPS_ANNOTATOR_SAM_MAX_POINTS=160
VISIONOPS_ANNOTATOR_SAM_SIMPLIFY_RATIO=0.0015
VISIONOPS_ANNOTATOR_SAM_ALLOW_DOWNLOAD=false
```

默认禁止由服务端自动下载模型，避免生产网络环境下出现不可控下载。

## 快速学习调整

Segmentation 快速学习新增默认参数：

```text
overlap_mask=False
mask_ratio=2
retina_masks=True
conf=0.15
iou=0.50
max_det=300
degrees=12
amp=True
```

其中 `overlap_mask=False` 用于保留 `foam_ring` 与 `ring_mouth` 这类嵌套实例的独立监督；`mask_ratio=2` 比原默认低分辨率掩膜保留更多小孔和边缘细节。

快速学习除检查“每类覆盖图片数”外，还检查“每类实例数”。默认至少：

```text
每类覆盖 3 张人工确认图片
每类 10 个人工确认实例
全部至少 5 张人工确认图片
```

这些阈值均可通过环境变量覆盖。

## 边界

- 当前仅实现 box prompt，不包含正点/负点交互。
- 当前不会自动搜索整张图中的所有目标。
- SAM 不负责类别判断，用户仍需选择类别。
- 模型权重和 GPU 环境需在实际 Server API 主机上部署。
- 本仓库自动化测试只验证接口逻辑、轮廓简化和模拟 SAM 输出，未替代真实 GPU 模型验证。
