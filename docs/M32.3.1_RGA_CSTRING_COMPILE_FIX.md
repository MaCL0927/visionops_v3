# M32.3.1 RGA compile fix

M32.3.1 fixes the LB3576 build error from Rockchip `im2d.hpp` where the
header expands helpers that call unqualified `memset` before it has been
declared.

Changed file:

- `edge/runtime_cpp/src/rga_preprocess.cpp`

The fix includes `<cstring>` before the Rockchip RGA headers. Runtime behavior,
ROI geometry, protocol fields, and model YAML remain unchanged.
