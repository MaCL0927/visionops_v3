# M32.7 App 全链路分段计时

M32.7 为 `production/detergent_grasp` 增加低开销的 App 全链路计时和滚动统计。
计时窗口默认保留最近 120 个完成结果，并通过 `/api/app/status` 暴露 latest/avg/p50/p95/max。

## 状态字段

```json
{
  "detection_fps": 24.6,
  "inference_stage_fps": 26.1,
  "latency_ms": {
    "latest": 43.1,
    "avg": 44.0,
    "p50": 42.7,
    "p95": 51.8,
    "max": 60.4,
    "samples": 120
  },
  "last_app_timing": {},
  "app_timing_stats": {}
}
```

`last_app_timing` 包含：

- `runtime_lock_wait_ms`
- `runtime_request_ms`
- `runtime_internal_ms`
- `runtime_outside_ms`
- `runtime_response_bytes`
- `inference_stage_ms`
- `result_queue_wait_ms`
- `runtime_validation_ms`
- `algorithm_ms`
- `robot_message_build_ms`
- `visualization_build_ms`
- `decision_build_ms`
- `websocket_send_ms`
- `websocket_clients_sent`
- `debug_enqueue_ms`
- `postprocess_stage_ms`
- `state_store_ms`
- `pipeline_age_ms`
- `total_ms`

其中 `total_ms` 与 `pipeline_age_ms` 是从 App 开始请求本帧 Runtime 到结果完成发布的端到端时间。
`runtime_response_bytes` 在当前 urllib RuntimeClient 中为 0；为了避免热路径重新序列化完整 JSON，M32.7 不为估算大小额外做一次 `json.dumps`。

## 查看

```bash
curl -s http://127.0.0.1:19212/api/app/status | python3 -m json.tool
```

只看关键统计：

```bash
curl -s http://127.0.0.1:19212/api/app/status | python3 -c '
import json,sys
x=json.load(sys.stdin)
print("output_fps", x.get("detection_fps"))
print("producer_fps", x.get("inference_stage_fps"))
print("latency", json.dumps(x.get("latency_ms"), ensure_ascii=False, indent=2))
print("last", json.dumps(x.get("last_app_timing"), ensure_ascii=False, indent=2))
print("stats", json.dumps(x.get("app_timing_stats"), ensure_ascii=False, indent=2))
'
```
