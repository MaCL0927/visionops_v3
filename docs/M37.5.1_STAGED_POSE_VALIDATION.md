# M37.5.1：姿态安全与快速质量解耦、轻量候选预筛选、最终候选延迟安全验证

## 目标

M37.5 对每个同层侧躺圆环都执行完整法向约束搜索、Top-K、多次 Bootstrap 和全点云验证。在 12 个圆环同层的场景中，单次触发会执行 12 次重型拟合，并追加一次局部高精度搜索，RK3576 实测达到约 52 秒。

M37.5.1 将流程拆为四级：

1. **轻量候选预筛选**：仅使用腐蚀 mask、有效深度比例、深度 IQR、深度跳变比例、邻实例接触比例和分割置信度排序；不做圆柱拟合。
2. **Preliminary Screen**：默认仅对同层前 3 个候选执行。使用 320 点、8 个轴线初值、Top-1、两级小范围局部搜索；不执行 P90、Top-K 歧义和 Bootstrap。
3. **Delayed Final Validation**：只有 preliminary pose-safe 候选才进入。以上一步轴线为初值，进行有界局部精修，并执行完整 P90、歧义、法向种子一致性和 Bootstrap 安全检查。
4. **单次局部高精度兜底**：只有当前层没有任何候选通过最终安全验证时才允许一次；不重新执行全局方向搜索。

## 关键语义

- `fit_score` 只用于质量分级和候选排序，不再作为姿态安全否决条件。
- `preliminary_pose_safe=true` 只表示通过了中心证据门限，仍不能直接输出机器人抓取结果。
- `final_pose_safe=true` 才允许成为 M37 抓取候选。
- 最终验证失败后尝试下一个轻量候选，而不是遍历同层所有实例。
