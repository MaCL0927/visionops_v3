# M36.4.2 单目标首个有效抓取提前退出与自适应钟点搜索

## 1. 目标

M36.4.1 已把所有完整候选压缩为少数全局候选，但仍会先对全部成功配对执行椭圆、深度反投影、RANSAC 平面和姿态计算。真机 4 个配对时，`pair_geometry_initial_ms` 约占几何耗时 70%。

M36.4.2 面向“一次触发只抓一个圆环”的生产需求，将在线默认模式改为 `first_valid`：

```text
全部 ring/mouth 配对
  -> 稀疏深度 + 配对质量低成本排序
  -> 逐个目标执行完整基础几何
  -> 每个目标先生成 8 个主方向轻量候选
  -> 按轻量得分逐个执行完整碰撞
  -> 首个有效候选立即返回
  -> 8 个主方向全部失败时才补 4 个方向
  -> 当前目标仍失败时才处理下一个目标
```

完整碰撞判定没有删除，只改变执行顺序和提前退出条件。

## 2. 三种模式

### first_valid（在线默认）

- 对匹配对只做稀疏深度与二维质量预排序；
- 最多完整分析 `maximum_pairs_to_fully_analyze` 个目标；
- 目标按预排序结果逐个处理；
- 每个目标先搜索 8 个主钟点；
- 完整候选按轻量得分逐个检查；
- 找到一个有效候选后立即停止该目标和整个场景；
- 主方向无有效候选时才补充剩余 4 个钟点；
- 未处理目标标记为 `deferred`，不误报为几何拒绝。

### staged（M36.4.1 兼容）

全部配对先完成基础几何，再从全场轻量候选中按预算执行完整碰撞。

### exhaustive（离线诊断兼容）

全部配对、全部 12 个方向都执行完整碰撞。

## 3. 目标预排序

预排序不执行三维点云和 RANSAC。每个配对只使用：

- ring 去除 mouth 后的稀疏前表面深度；
- 有效深度比例；
- association score 与 containment；
- ring/mouth 平均分割置信度。

默认优先选择深度更小、即更靠近相机的顶层目标。若第一目标最终因姿态、箱壁、邻环或夹爪碰撞失败，会自动尝试下一目标。

## 4. 自适应 8+4 钟点

保持原 12 个整数钟点定义，不引入 4:30 等新角度。默认主方向：

```text
12, 2, 3, 5, 6, 8, 9, 11
```

补充方向：

```text
1, 4, 7, 10
```

每一批都先做轻量评分，再按得分逐个进行完整箱壁、邻环点云和完整夹爪静态碰撞。第一项完整有效候选出现后立即停止。

## 5. 配置

```yaml
geometry_optimization:
  enabled: true
  mode: first_valid
  timing_enabled: true
  skip_rejected_pairs: true
  prefer_top_layer: true
  cache_neighbor_point_clouds: true
  stop_after_first_valid_target: true
  stop_after_first_valid_candidate: true
  maximum_pairs_to_fully_analyze: 3
  maximum_full_candidates_per_pair: 12

pair_preselection:
  enabled: true
  depth_sample_stride: 4
  ring_erode_px: 1
  mouth_exclusion_px: 2

clock_search:
  mode: adaptive_8_plus_4
  primary_clock_hours: [12, 2, 3, 5, 6, 8, 9, 11]
  fallback_to_remaining: true
```

`maximum_full_candidates_per_pair=12` 保证最坏情况下仍能覆盖全部方向。正常场景通常只完整检查 1 个候选。

## 6. 运行与 A/B 对照

默认 first_valid：

```bash
cd /opt/visionops_v3
bash production/foam_ring_grasp/scripts/run_online_geometry_once.sh
```

显式指定：

```bash
VISIONOPS_FOAM_RING_GEOMETRY_MODE=first_valid \
  bash production/foam_ring_grasp/scripts/run_online_geometry_once.sh
```

M36.4.1 staged 对照：

```bash
VISIONOPS_FOAM_RING_GEOMETRY_MODE=staged \
  bash production/foam_ring_grasp/scripts/run_online_geometry_once.sh
```

完整 exhaustive 对照：

```bash
VISIONOPS_FOAM_RING_GEOMETRY_MODE=exhaustive \
  bash production/foam_ring_grasp/scripts/run_online_geometry_once.sh
```

## 7. 新增诊断字段

`scene.geometry_optimization`：

```text
pair_preselection_count
fully_analyzed_pair_count
deferred_pair_count
primary_light_candidate_count
fallback_light_candidate_count
adaptive_fallback_used
full_candidate_evaluated_count
full_candidate_valid_count
first_valid_pair_rank
first_valid_candidate_search_batch
first_valid_candidate_clock_hour
early_exit_triggered
```

`scene.timing_ms` 新增：

```text
pair_preselection_ms
adaptive_fallback_light_ms
```

场景结果新增：

```text
selected_clock_angle_deg_cw_from_12
selected_clock_search_batch
```

未处理配对使用：

```json
{
  "processing_status": "deferred",
  "deferred_reason": "after_first_valid_target"
}
```

## 8. 验收重点

连续运行 5~10 次，重点观察：

- `fully_analyzed_pair_count` 通常是否为 1；
- `full_candidate_evaluated_count` 通常是否为 1；
- `early_exit_triggered` 是否为 `true`；
- `adaptive_fallback_used` 是否大多数时候为 `false`；
- 第一目标失败时是否自动分析第二目标；
- `selected_ring_instance_id` 和 `selected_clock_hour` 是否稳定；
- 与同帧 `staged`/`exhaustive` 的碰撞状态是否一致。

`first_valid` 的目标是尽快返回一个完整有效抓取，不保证选择全场分数最高的抓取。如果未来需要全场最优目标，切换回 `staged` 或 `exhaustive`。
