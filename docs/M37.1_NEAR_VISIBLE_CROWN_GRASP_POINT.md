# M37.1：近端可见弧面抓取点修正

## 问题

M37 初版的短圆柱轴线、中心和近远端判断可以正常工作，但抓取点定义为：

- 近端开口平面；
- 内外壁中线半径；
- 投影到图像后纵坐标最小的圆周点。

这个点是“开口边缘的投影最高点”，不是侧躺圆环近端外圆柱面上的实际抓取点。对于真实实例 7，旧点约为 `(243.18, 172.81)`，而人工确认的位置为 `(256, 199)`。

## 真实 RGB-D 反算

在 `1785833810687` 调试帧中，人工点 `(256, 199)`：

- 位于 `foam_ring` mask 内；
- 深度约 610 mm；
- 相对拟合近端沿轴线向内部约 11 mm；
- 到圆柱轴线的径向距离约 42.4 mm，与名义外半径 42.5 mm 一致。

因此 M37.1 将物理点定义为“近端开口后方的相机可见外圆柱弧面点”。

## 新算法

1. 保持 M37 的短圆柱轴线、中心和近远端判断不变。
2. 从近端沿轴线向内部缩进 `grasp_axial_inset_mm`，默认 11 mm。
3. 只使用径向拟合内点中、位于近端后方 5–22 mm 轴向带内的点。
4. 将这些点转换成圆柱截面上的径向角度。
5. 通过圆周最大间隙识别不可见区，剩余连续角区间视为相机可见弧面。
6. 对可见角区间两端各裁掉 1% 的异常角度。
7. 投影两个弧端，确定图像位置更高的一端。
8. 从较高端向较低端移动 `visible_crown_upper_fraction`，默认 0.44。
9. 使用名义外半径 42.5 mm 生成最终三维抓取点。
10. 如果可见弧面点数不足、角跨度异常或方向背向相机，则回退到“相机朝向径向”。

`visible_crown_upper_fraction` 描述工艺上希望接触的弧面位置，而不是圆柱固有参数，因此保留为可配置项。

## 默认配置

```yaml
side_ring_template:
  grasp_radius_mode: outer_surface
  grasp_axial_inset_mm: 11.0

  visible_crown_enabled: true
  visible_crown_axial_band_start_mm: 5.0
  visible_crown_axial_band_end_mm: 22.0
  visible_crown_minimum_points: 80
  visible_crown_angular_trim_quantile: 0.01
  visible_crown_upper_fraction: 0.44
  visible_crown_minimum_span_deg: 35.0
  visible_crown_maximum_span_deg: 175.0
  visible_crown_fallback_mode: camera_facing
```

新增：

```json
{
  "near_side_crown": {
    "definition": "camera_visible_cylindrical_arc_point_inset_from_near_opening",
    "radius_mm": 42.5,
    "radius_mode": "outer_surface",
    "grasp_axial_inset_mm": 11.0,
    "grasp_circle_center_camera_mm": [],
    "radial_direction_camera": [],
    "direction_source": "visible_surface_angular_interval",
    "visible_arc": {},
    "grasp_point_camera_mm": [],
    "grasp_point_uv": []
  }
}
```

旧点保留为：

```json
{
  "near_opening_rim_top_diagnostic": {
    "definition": "legacy_near_opening_wall_midline_highest_projected_point",
    "point_camera_mm": [],
    "point_uv": []
  }
}
```

`top_arc.grasp_point_*` 仍保留为兼容别名，但已指向 M37.1 新抓取点。

## 实例 7 验证

M37.1 本地真实帧输出：

- 新抓取点：`(256.07, 199.07)`；
- 人工标注中心：`(256, 199)`；
- 像素误差约 0.10 px；
- 轴向内缩：11 mm；
- 抓取半径：42.5 mm；
- 可见弧面点数：1108；
- 可见角跨度：107.67°；
- 方向来源：`visible_surface_angular_interval`。

叠加图标记：

- 红色方框：M37.1 新抓取点；
- 白色斜十字：M37 旧开口边缘最高点；
