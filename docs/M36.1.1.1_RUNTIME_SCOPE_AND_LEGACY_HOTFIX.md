# M36.1.1.1 Runtime scope and legacy compatibility hotfix

This hotfix narrows the high-resolution segmentation mask decoder to explicit
per-model opt-in.

- Detection, OBB and classification do not execute segmentation mask decoding.
- Existing and newly packaged segmentation models default to `legacy_proto`.
- `legacy_proto` restores the exact pre-M36.1.1 behavior: sigmoid threshold 0.5
  and fixed 2.0 px polygon simplification epsilon.
- The foam-ring model can opt in with:

```yaml
postprocess:
  mask_decode_mode: ultralytics_highres
  mask_threshold: 0.5
  mask_polygon_epsilon_px: 0.75
  mask_max_points: 160
```

Because C++ public structs changed in M36.1.1, deployment must use a clean
Runtime rebuild. Reusing an old `build-rknn` directory can leave incompatible
object files and may produce heap corruption. Run:

```bash
cd /opt/visionops_v3
bash scripts/rebuild_runtime_rknn_clean.sh
```
