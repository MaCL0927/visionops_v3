# M38.2：部分开口与局部外圆柱联合分支

## 1. 目标和边界

M38.2 实现 M38 分支 B，面向以下实例：

- `ring_mouth` 只分割出部分开口或部分端部；
- 同时能看到开口后方连续的外圆柱侧面；
- 机械抓取仍然只能采用一个手指进内孔、一个手指位于外侧的内外夹持。

本分支不接受“只看到外侧壁、完全没有开口或端部证据”的目标。局部圆柱拟合成功只说明轴线和中心线可恢复，只有部分开口、近端端部以及内孔入口也通过验证时，才会进入原有 rim-pinch 与碰撞检查。

M38.1、M36、M37.6 均保留。M38.2 可通过配置独立关闭。

## 2. 当前混合分支顺序

```text
一次 Runtime 分割 + 精确同步 RGB-D
  -> 全局搜索所有已配对实例的 M38.1 清晰开口
     -> 找到完整可抓候选：立即返回
  -> 全局搜索最多 N 个已配对实例的 M38.2 部分开口
     -> 局部侧面/端部证据通过
     -> 原 rim-pinch 与完整碰撞检查通过：立即返回
  -> M38.1/M38.2 均无候选
     -> 按前表面深度从近到远运行旧 M36
     -> 旧 M37.6 screen/final fallback
```

此顺序同时修复了 M38.1 中发现的跨深度层优先级问题：不会再先对浅层侧躺实例执行数秒 M37.6，再检查稍深层已经存在的清晰或部分开口。

## 3. 可观测侧面提取

对一个已配对的 `foam_ring + ring_mouth`：

1. 腐蚀 `foam_ring` mask，去除分割边缘；
2. 排除 `ring_mouth` 及其膨胀区域；
3. 排除其他圆环实例及邻域；
4. 使用 ring 中心到 mouth 中心的二维方向定义轴向端部方向；
5. 只保留开口后方一定轴向范围内的侧面带；
6. 去除深度跳变像素；
7. 保留足够大的连通区域；
8. 反投影侧面深度点，并由组织化 RGB-D 邻域计算局部法向。

若 mouth 不能提供明显的端部方向，或 containment、面积比例不满足条件，分支会在进入圆柱优化前快速拒绝。

## 4. 局部法向初始化与定半径圆柱拟合

轴线初值来自三类证据：

- 外侧面法向协方差矩阵最小特征向量；
- 侧面点云 PCA 长轴；
- ring 中心到部分 mouth 中心的二维方向反投影初值。

随后使用已知外半径的解析局部圆柱模型，只优化轴线方向和中心线位置。点到圆柱的径向残差为：

```text
abs(norm((p-c)-a*dot(a,p-c))-R_outer)
```

为了控制在线耗时，不执行全局 ICP 或密集姿态遍历。实现采用分层局部搜索：

1. 评估少量初值；
2. 对初值做第一层角度扰动；
3. 只保留得分最好的 Top-K；
4. 对 Top-K 做第二层小角度精修。

当前典型候选轴数量约 51，而不是 M37.6 的大规模多曲面搜索。

## 5. 部分端部与开口安全门

圆柱拟合后仍必须验证真实开口证据：

- 在 mouth 周边构造部分端部支持区域；
- 沿拟合轴线只提取朝向开口的轴向极值点；
- 对这些极值点做一维鲁棒端面定位；
- 验证端部内点数、内点比例和 P90 残差；
- 检查拟合开口中心与分割 mouth 中心的一致性；
- 检查原 mouth 与拟合内孔投影的重叠率；
- 确认该端是相机较近端，并且轴线从圆柱体指向可见开口；
- 限制轴线与视线夹角：近似正视属于 M38.1，完全不可进入的极端侧视被拒绝。

只有上述测量证据全部通过后，才在已定位的开口平面上按名义内径和外径投影完整内孔与外轮廓。原始部分 `ring_mouth` 必须与拟合内孔保持足够重叠；合成内外投影只用于恢复该开口截面的名义壁厚，并复用现有内夹爪 containment、外边界、钟点搜索和碰撞逻辑，不能把原本完全不可见的开口变成“已观测开口”。

## 6. 抓取与碰撞逻辑

M38.2 不增加外侧壁夹取模式。姿态恢复后继续使用现有：

- 内外 rim-pinch；
- 8+4 自适应钟点搜索；
- 内夹爪进入内孔的 containment；
- 外夹爪位置；
- 箱壁、邻居点云、完整夹爪静态碰撞；
- 预抓取与插入运动碰撞。

如果局部圆柱和部分端部拟合通过，但没有任何钟点通过完整碰撞检查，则 M38.2 不输出候选，并继续回退旧分支。

输出分支名：

```text
m38_2_partial_opening_local_cylinder_rim_pinch
```

姿态来源：

```text
partial_mouth_plus_local_outer_cylinder
```

生产配置位于 `production/foam_ring_grasp/config/line.yaml`：

```yaml

  enabled: true
  fallback_to_m36: true
  maximum_candidates_per_trigger: 4

  minimum_mouth_containment: 0.28
  minimum_ring_mouth_center_offset_px: 3.0
  minimum_partial_mouth_overlap_ratio: 0.42

  minimum_side_points: 80
  minimum_normal_points: 40
  maximum_fit_points: 600
  local_refine_angles_deg: [7.0, 2.5]
  local_refine_top_k: 3
  radial_inlier_threshold_mm: 6.0
  minimum_radial_inlier_ratio: 0.55

  minimum_axis_view_angle_deg: 24.0
  maximum_axis_view_angle_deg: 88.0

  minimum_endpoint_support_points: 20
  minimum_endpoint_plane_inlier_ratio: 0.08
```

只关闭分支 B：

```yaml

  enabled: false
```

M38.1 和旧 M36/M37.6 不受影响。

## 10. 开发机回放结论

对 5 组 M37.6 问题帧和 3 组 M38.1 在线保存帧进行了分支 B 独立回放：

- 共 8 帧、26 个配对实例；
- 5 个实例通过局部侧面圆柱、部分端部和原始 mouth 重叠门限；
- 通过实例均评估约 51 条局部轴线，不执行全局 ICP；
- 所有配对调用的开发容器耗时：中位数约 `119 ms`，P95 约 `139 ms`；不满足端部方向的实例可在约 `1 ms` 内快速拒绝；
- 5 个通过局部拟合的实例耗时约 `122–139 ms`；
- 每帧分支 B 独立回放总耗时约 `0.13–0.63 s`，取决于配对数量和是否进入完整夹爪验证；
- 合成内外开口投影后，32 个轻量候选均能得到合理壁厚，范围约 `11.55–13.78 mm`，不再出现原始侧视 mask 引起的 `wall_thickness_out_of_range` 和 `outer_rim_boundary_unavailable`；
- 这些拥挤样例中仍没有最终 M38.2 机器人候选。完整验证的拒绝来自真实邻居点云/夹爪碰撞，以及离线保存包未配置箱体标定，而不是局部圆柱或开口壁厚求解失败；
- 这符合安全边界：局部模板匹配成功不等于机械可抓取。

上述是开发机离线结果，不代表 RK3576 真机耗时。尚未完成 336L 实时服务和机器人实际抓取验证。
