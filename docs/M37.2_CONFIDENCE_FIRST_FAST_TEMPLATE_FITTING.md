# M37.2：置信度优先与首个有效侧躺圆环快速拟合

## 目标

M37.1 会对当前帧中所有没有可靠 `ring_mouth` 的 `foam_ring` 实例逐一执行参数化短圆柱拟合。真实调试帧中 10 个候选全部拟合约需 6.6～7.3 秒，但机器人一次只需要抓取一个目标。

M37.2 将默认执行策略改为：

1. 按 `foam_ring` 分割置信度从高到低排序；
2. 只拟合当前排名最高的实例；
3. 拟合和质量门通过后立即返回；
4. 当前实例失败才继续下一实例；
5. 仍保留 `exhaustive` 高精度全量模式用于离线诊断。

## 默认流程

```text
全部未匹配 ring_mouth 的 foam_ring
        ↓
按 confidence 降序排列
        ↓
快速粗到细短圆柱拟合
        ↓
质量充分 → 计算近端可见弧面抓取点 → 立即退出
        ↓
质量不足 → 自动高精度回退
        ↓
仍失败 → 继续下一个 foam_ring
```

未处理实例会在 JSON 中标记：

```json
{
  "processing_status": "deferred",
  "deferred_reason": "after_first_valid_confidence_candidate"
}
```

## 快速轴线搜索

M37.1 高精度配置保持不变：

```yaml
maximum_fit_points: 1200
global_axis_samples: 320
local_refine_radial_steps: 3
local_refine_azimuth_steps: 16
fixed_radius_iterations: 12
```

M37.2 新增快速配置：

```yaml
fast_maximum_fit_points: 700
fast_global_axis_samples: 80
fast_local_refine_radial_steps: 2
fast_local_refine_azimuth_steps: 12
fast_fixed_radius_iterations: 6
```

快速结果满足以下任一条件时会自动重新执行高精度搜索：

- `fit_score > fast_accept_max_score`；
- 径向内点率不足；
- 径向中位残差或 P90 残差超限；
- 可见轴向跨度超限。

因此快速模式不会在明显低质量结果上直接给出抓取点。

## 其他优化

- 深度点只在当前实例 bbox 内提取，不再扫描完整 ROI；
- 全局 Fibonacci 方向集合按采样数量缓存；
- 首个成功后不再生成其他实例的模板曲线和 PLY；
- 默认 first-valid 模式只保存所选实例的 PLY；
- 保留全部分阶段耗时与搜索候选数量。

## 配置

```yaml
side_ring_template:
  execution_mode: first_valid_confidence
  stop_after_first_eligible: true
  maximum_instances_to_attempt: 0
  first_valid_search_profile: auto
  exhaustive_search_profile: accurate

  point_extraction_bbox_padding_px: 3
  minimum_depth_points: 80

  fast_search_enabled: true
  fast_maximum_fit_points: 700
  fast_global_axis_samples: 80
  fast_local_refine_angles_deg: [12.0, 4.0, 1.5]
  fast_local_refine_radial_steps: 2
  fast_local_refine_azimuth_steps: 12
  fast_fixed_radius_iterations: 6
  fast_accept_max_score: 3.0
  accurate_fallback_enabled: true
  accurate_fallback_on_quality_gate_failure: true
```

## 命令

默认快速首个有效模式：

```bash
bash production/foam_ring_grasp/scripts/run_m37_side_ring_offline.sh \
  /path/to/M36_debug_bundle
```

指定实例：

```bash
bash production/foam_ring_grasp/scripts/run_m37_side_ring_offline.sh \
  /path/to/M36_debug_bundle \
  --instance-id 7
```

完整高精度对照：

```bash
bash production/foam_ring_grasp/scripts/run_m37_side_ring_offline.sh \
  /path/to/M36_debug_bundle \
  --mode exhaustive \
  --search-profile accurate
```

强制只用快速搜索、不执行高精度回退：

```bash
bash production/foam_ring_grasp/scripts/run_m37_side_ring_offline.sh \
  /path/to/M36_debug_bundle \
  --search-profile fast
```

## 真实帧验证

数据：`1785833810687`。

M37.1 全量高精度：

- 候选数：10；
- 实际拟合：10；
- 内部拟合总耗时约 6.6 秒；
- 命令墙钟耗时约 7.3 秒。

M37.2 默认模式：

- 候选数：10；
- 实际拟合：1；
- 延后处理：9；
- 所选实例：0；
- 场景内部总耗时约 166～168 ms；
- 轴线拟合约 132 ms；
- 命令墙钟耗时约 0.86 秒，其中包含 Python/OpenCV 启动与文件读取。

实例 7 的抓取点保持为约 `(256.08, 199.11)`，与 M37.1 修正结果一致。
