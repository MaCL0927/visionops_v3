# M38.1：开口清楚可见时的三维端面环带分支

## 1. 目标

M38.1 只实现 M38 的分支 A：当 `foam_ring` 与 `ring_mouth` 已可靠配对、开口轮廓清楚可见时，不再使用 M36 的“二维椭圆法向与局部深度平面融合/冲突判断”，而是直接从开口周围可观测的泡沫端面环带恢复三维平面与圆环轴线。

本阶段不删除旧分支：

1. M38.1 分支 A 优先；
2. M38.1 未找到完整可抓候选时，可回退旧 M36；
3. M36 仍失败时，继续进入原 M37.6；
4. M37.6.1 的止损策略继续生效，在线 `local_accurate` 保持关闭。

## 2. 处理顺序

```text
深度层由近到远
  -> 同层已配对 ring/mouth
     -> M38.1 三维端面环带
        -> 成功：沿用原 rim-pinch/碰撞验证并返回
        -> 失败：可配置回退 M36
     -> M36 失败
        -> 原 M37.6 screen/final 流程
```

## 3. 三维端面环带构造

对于一个已配对实例：

1. 对 `foam_ring` mask 向内腐蚀，减小分割边缘与 D2C 混合深度影响；
2. 以 `ring_mouth` 等效半径为尺度向外膨胀，限制端面环带的外边界；
3. 对 `ring_mouth` 小范围膨胀并排除，避免内孔背景和内壁混入；
4. 排除其他 `foam_ring` mask 及其邻域；
5. 检测四邻域深度跳变，排除跳变两侧像素；
6. 将保留像素反投影为三维点；
7. 使用原有平面 RANSAC + SVD 精修拟合端面环带。

二维椭圆仅用于：

- 定位开口中心；
- 构造环带范围；
- 检查开口完整度；
- 在三维端面上计算内孔尺寸。

二维椭圆不再产生三维法向，也不再与深度平面进行法向冲突硬判断。圆环轴线直接取三维端面环带平面的朝向相机法向。

## 4. 清晰开口门控

分支 A 默认要求：

- 配对模式为 `strict_envelope`，不接受 bbox fallback；
- mouth containment 和 mouth/ring 面积比例处于合理范围；
- 椭圆短长轴比不能过小；
- 椭圆轮廓归一化残差不能过大；
- 环带深度点数量与有效比例足够；
- 环带点和 RANSAC 内点覆盖足够多的角度扇区；
- 平面内点率和 P95 残差满足阈值。

失败原因统一使用 `m38a_*` 前缀，例如：

- `m38a_opening_association_not_strict`
- `m38a_mouth_ellipse_too_flat`
- `m38a_insufficient_annulus_depth`
- `m38a_annulus_angular_coverage_too_small`
- `m38a_annulus_plane_inlier_ratio_too_low`
- `m38a_annulus_plane_residual_too_high`

## 5. 现有抓取与碰撞逻辑保持不变

M38.1 只替换清晰开口实例的姿态来源。姿态确定后继续复用原有：

- 开口尺寸和壁厚计算；
- 8+4 自适应钟点搜索；
- 内外夹持点生成；
- 箱壁检查；
- 邻居点云碰撞；
- 完整夹爪静态与运动检查；
- 原机器人候选数据结构。

输出分支名：

```text
m38_1_clear_mouth_front_annulus_rim_pinch
```

## 6. 配置

生产配置位于 `production/foam_ring_grasp/config/line.yaml`：

```yaml
m38_branch_a:
  enabled: true
  fallback_to_m36: true
  require_strict_association: true
  minimum_mouth_containment: 0.65
  minimum_mouth_minor_major_ratio: 0.35
  ring_mask_erode_px: 2
  annulus_outer_expand_ratio: 0.55
  mouth_inner_exclusion_px: 2
  depth_edge_threshold_mm: 22.0
  angular_sector_count: 16
  minimum_angular_coverage_deg: 180.0
  minimum_inlier_angular_coverage_deg: 160.0
  minimum_valid_points: 80
  minimum_plane_inlier_ratio: 0.45
  maximum_plane_residual_p95_mm: 7.0
```

关闭 M38.1、完全恢复 M37.6.1 顺序：

```yaml
m38_branch_a:
  enabled: false
```

保留 M38.1，但不再回退旧 M36：

```yaml
m38_branch_a:
  enabled: true
  fallback_to_m36: false
```

顶层新增：

- `selected_grasp_branch`
- `m38_1_robot_candidate`
- `m38_1_eligible_count`

`m38_1_branch_a.pair_results` 包含：

可视化中 M38.1 环带使用青黄色半透明区域，姿态来源标签为 `[A]`；旧 M36 深度面/椭圆来源仍显示 `[D]`/`[E]`。

## 9. 当前开发机回放结果

使用用户提供的 5 组 M37.6 问题帧回放：

- 14 个配对实例进入 M38.1 诊断；
- 分支 A 单独处理每帧约 90–409 ms（开发机，不代表 RK3576）；
- 多个开口实例得到稳定的三维环带平面，典型平面内点率约 0.49–0.66、P95 残差约 2.7–4.6 mm；
- 这些问题帧中没有 M38.1 最终通过全部夹爪/碰撞检查的目标，因此实际混合流程仍按配置回退 M36/M37.6；
- 原 M37.6 代码和输出结构未删除。

当前仅完成开发机离线验证，尚未在 RK3576 + 336L + 机器人上验证真实耗时与抓取成功率。
